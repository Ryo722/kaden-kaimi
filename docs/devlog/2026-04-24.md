### 仕様確定の判断（logic-specs.md を先に更新）

実装中に仕様が曖昧だった箇所を、logic-specs.md を先に更新してから実装に落とし込んだ：

- **軸1**: `score = featureMatchRatio × 0.7 + priceDiffNormalized × 0.3`、一致率は target 基準の非対称。`priceDiff` 出力は `candidate.msrp - target.msrp`（現在価格統合は Phase 2 で UI 側に移譲）。同点時は id 昇順で決定的ソート。
- **軸2**: 境界値は下側カテゴリに倒す（`x<5 / 5≤x<8 / 8≤x<12 / 12≤x`）。`current: null` で `null` を返し軸スキップ。
- **軸3**: `CycleInput` に `targetCurrentPrice: number | null` を追加。祖先 0 件で `confidence: "none"` + 各値の規約を明記。価格履歴欠損祖先は値下がり率集計から除外。
- **軸5**: `predecessor: null` で空結果を返す。コスト換算は UI 側が軸2 と組み合わせる責務分離に整理。`washCapacityKg` は kg 絶対値閾値、`annualKwh` / `waterPerCycleL` は % 閾値。
- **軸6**: 入力に `candidates` / `currentPrices` / `currentModel` / `rates` を追加。容量適合は `ideal = householdSize × 1.5`, `score = 30 × max(0, 1 - |diff|/AXIS6_CAPACITY_TOLERANCE_KG)`。`currentPrices` に該当 id 無しなら `msrp` 代替。
