### Wrangler 起動時の摩擦

`pnpm --filter kaden-kaimi-fetch-prices exec wrangler dev --test-scheduled --port 8787` がエラー:

```
✘ [ERROR] Found both a user configuration file at "wrangler.toml"
  and a deploy configuration file at "../../.wrangler/deploy/config.json".
```

原因: プロジェクトルート `.wrangler/deploy/config.json` は Astro Cloudflare adapter が `astro build` 時に生成した deploy 設定で、`dist/server/wrangler.json` を指す。Wrangler が `workers/fetch-prices/` 起動時に親ディレクトリを遡って検出し、base path 不一致で reject していた。

回避: `--config wrangler.toml` を明示するか、ルート `.wrangler/deploy/` を削除（gitignore 済みなので副作用なし、次の astro build で再生成）。

恒久対応の候補（フォローアップ別タスクで検討）:
- `workers/fetch-prices/package.json` に `"dryrun": "wrangler dev --config wrangler.toml --test-scheduled --port 8787"` を追加
- ルート側 `.wrangler/deploy` を astro build 後に自動削除する postbuild フック
