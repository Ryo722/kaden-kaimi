## T-008: Upload Lighthouse artifacts no-files warning 修正

ブランチ `fix/lighthouse-artifact-upload` を `origin/main` から切って実施。

### 原因特定

run 24979704717 の `Run Lighthouse CI on preview URL` ステップ末尾は以下:

```
Uploading median LHR of https://kaden-kaimi.pages.dev/...success!
Open the report at https://storage.googleapis.com/lighthouse-infrastructure.appspot.com/reports/1777270990554-81855.report.html
Uploading median LHR of https://kaden-kaimi.pages.dev/washers/panasonic-na-lx129dl/...success!
Open the report at https://storage.googleapis.com/lighthouse-infrastructure.appspot.com/reports/1777270990857-2983.report.html
No GitHub token set, skipping GitHub status check.

Done running autorun.
```

`Healthcheck passed!` 段で `✅ .lighthouseci/ directory writable` と出ており、`lhci collect` は `.lighthouseci/lhr-*.json/html` を生成しているはず。ローカル `.lighthouseci/` には過去 run の `lhr-1777032855075.{html,json}` 等が実在し、`lhci autorun` の出力先は `.lighthouseci/` で確定。

→ 原因は **lhci 側ではなく `actions/upload-artifact@v4` の glob 挙動**。v4 はデフォルトで dot 始まりパス（hidden file/dir）を除外する仕様であり、`.lighthouseci/` ディレクトリ自体が `.` で始まるため glob から脱落し "No files were found" warning となる。`actions/upload-artifact` README で明示されており、`include-hidden-files: true` で対象に含められる。

### 修正

`.github/workflows/lighthouse-preview.yml` の Upload ステップに `include-hidden-files: true` を追加。`.lighthouseci/` 配下の `lhr-*.{json,html}` / `links.json` / `assertion-results.json` は計測結果のみで機密情報を含まないため、hidden 制限を解除して問題ない。

```yaml
- name: Upload Lighthouse artifacts
  if: always()
  uses: actions/upload-artifact@v4
  with:
    name: lighthouse-preview-reports${{ ... }}
    path: .lighthouseci/
    retention-days: 14
    include-hidden-files: true   # ← 追加
```

### 検証方針

- 受け入れ条件: マージ後の Lighthouse CI (preview URL) run で `lighthouse-preview-reports`（または `-fallback`）artifact が GitHub Actions 上に保存される
- 検証コマンド: `gh api repos/Ryo722/kaden-kaimi/actions/runs/<id>/artifacts` で `total_count >= 1`
- マージ後の verify step で T-008 を `state: implemented` + `verified_at` 記録に更新する
