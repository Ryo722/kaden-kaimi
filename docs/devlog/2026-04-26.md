### P2.5.D2 クライアント実装
- `RakutenSearchInput` / `YahooSearchInput` に `minPrice?: number` を追加（オプショナル、未指定または 0 で無効）
- 楽天: URL クエリ `minPrice` を送出 + `parseRakutenPayload` 内で `price < minPrice` のヒットを continue で除外
- Yahoo!: URL クエリ `price_from` を送出 + `parseYahooPayload` 内で同様に除外（V3 の正式名は `price_from`）
- `pipeline.ts` で `const minPrice = CATEGORY_PRICE_FLOOR[category]` を取り、`searchRakuten` / `searchYahoo` に渡す
- 二段フィルタ（API 側 + クライアント側）の理由: API 側だけだと将来仕様変更で無視されたとき静かに失敗する。クライアント側だけだと top-5 全部が部品で埋まると実機が拾えない。両方かけて防御を厚くする
